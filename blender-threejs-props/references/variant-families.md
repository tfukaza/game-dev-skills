# Coherent prop families

Define plausible differences between objects, not arbitrary deformation to conceal duplication.

A family records nominal dimensions, pivot/support anchors, compatible geometry and artwork variants, stable seeds, allowed scale range, material options and per-detail roots. Keep fixed brand identity separate from intentionally variable serials, label wear or placement.

Coordinate geometry and appearance: a chipped corner needs matching exposed substrate; a replaced plank changes grain direction and joins; cloth sag must still meet its ties. Make a genuinely different shape/size as an authored or regenerated geometry variant with correct thicknesses and construction. Nonuniform mesh scaling, shear and mirrored text-bearing duplicates are not the default variation mechanism.

Use bounded uniform placement scale only where the object's type permits it. Manufactured equipment may allow almost none; foliage allows more. Never impose one universal percentage. Contact and collision must follow the resulting visible geometry.

Seed by persistent placement/variant ID and parameter name, not array position, load order or frame time. Detail changes simplify the same object; they must not reroll graphics, crown shape or lighting assignment. Stable instance metadata must survive batch compaction.

Bound the library and material combinations. Shared atlases, appropriate instance attributes and a finite set of compatible material/geometry groups can supply diversity without a separate full texture set/material for every placement. Do not randomize legible text with arbitrary UV rotations.

The parameter helper in [prop contracts](prop-contracts.md) generates stable choices; it does not verify that arbitrary parameters produce good art. Review a repeated group in context and across LOD transitions, not only isolated turntables.

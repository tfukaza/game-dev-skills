# Blender UV mapping and generated textures

Use this workflow when image-generated artwork must fit a modeled prop's specific surfaces. Author and inspect the UVs in Blender using its available tools; when the user requests computer use, use the live Blender UI for the requested inspection and verification. Scripts can assist mesh or UV construction, but a scripted rectangle diagram is not evidence that it represents the actual model's active UV channel.

## Establish the real layout

1. Model and inspect the object's volumes first. Settle scale, topology and material regions that affect the unwrap. Texture generation should follow the proportion/clay review, because changing the mesh or UVs can invalidate the artwork.
2. Mark seams along sensible panel boundaries or less visible surfaces, then unwrap the actual modeled mesh. Choose a clearly named UV channel and explicitly bind it in the intended material. Avoid unintentional island overlap; deliberate reuse or mirroring is suitable only where the artwork and orientation permit it.
3. Apply a checker and inspect the model and UV Editor. Correct stretched checks, inverted orientation, accidental stacking and uneven texel density. Give important visible graphics sufficient area. Leave island gutters and plan texture bleed for the chosen texture resolution and mip levels; do not put unrelated colors directly against an island edge.
4. Export the actual UV layout from Blender at the intended artwork resolution. Record the image size, UV channel, object/material assignment and model/UV revision. Inspect the exported image at readable scale. Create a small semantic manifest identifying which islands correspond to visible panels, their bounds, front/up direction and any intended overlaps. UV coordinates use bottom-left origin; ordinary raster coordinates use top-left. For a W×H image, the continuous pixel-boundary position is x=uW, y=(1-v)H. Check boundary and pixel-center conventions when assigning exact pixels.

A repeating physical-scale material is a different case: UVs may extend outside 0–1 and reuse a seamless tile. A representative checker or one-metre swatch must not be described as the object's packed UV atlas. Use repeat wrapping for that material and verify physical scale on the actual surface.

## Generate and reapply

5. Pass the exported UV layout as an actual image-generation reference, together with the semantic manifest and the intended design. A prompt describing rectangles without the image does not satisfy this step. Ask for flat, unlit surface artwork aligned to those islands, preserving canvas proportions and panel orientation. Request edge bleed outside islands, no visible UV guide lines, and no cast shadows or baked specular highlights in base color. Supply additional design references only as needed; create original artwork rather than copying a reference photograph's texture.
6. Inspect the generated image against the exported layout before applying it. Image generation can shift, resize or reinterpret boundaries; it does not guarantee exact pixel registration. Verify actual output dimensions and alignment of recognizable motifs, panel borders and small islands. If they drift, revise against the same guide or map canonical artwork through an explicit projection/bake. Do not relabel approximate alignment as pixel-exact. Keep the guide separate from the final texture so inspection lines are not painted onto the model.
7. Reapply the texture in Blender with an explicit UV Map node or equivalent channel binding, correct color space and appropriate image wrapping. Check the full material from front, side, rear and three-quarter views, plus close-ups at seams and important artwork. Look for gutter leakage, rotated or mirrored graphics, stretched patterns and markings on unintended faces. Compare textured and clay views: material detail must not conceal unresolved geometry.
8. Correct the responsible stage and inspect again. UV edits require a fresh export and texture alignment check; geometry changes may require a new unwrap. Preserve the final UV layout, source textures, prompts and manifest with the editable model, and pack images or use verified relative paths. If a runtime export is requested, inspect that export too, confirming UV channel and material bindings survive.

Include the checker/clay and textured views, actual UV export and applied texture in the [independent review](../../blender-threejs-props/references/evaluation.md) for substantial asset creation or polish. A reviewer must inspect the mapped model, not approve the texture sheet alone.

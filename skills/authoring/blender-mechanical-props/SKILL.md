# Mechanical Blender props

Establish the assembly architecture before refining component geometry. Mesh/object counts, visual components, rigid modules and bogie/hinge groups describe different things; do not substitute one for another.

Read [assembly modeling](references/assembly-modeling.md) for source-grounded module graphs, repeated hardware, joined surfaces and functional-state checks. Use the shared [source-to-model workflow](../blender-threejs-props/references/reference-modeling.md) for original-image inventory, simple mockups and one-angle generation anchored to actual renders. Every author/reviewer personally inspects the relevant originals.

For coaster vehicles, also use [roller coaster cars](../roller-coaster-cars/SKILL.md); establish the target family rather than treating all trains as one architecture. For actual UV work use [Blender UV textures](../blender-uv-textures/SKILL.md) after geometry/proportions are settled. Do not regenerate references for a simple placement or material-only change.

A plausible-looking shell or one wheel of each functional role does not prove source fidelity. Verify visible minima, assembly coverage and interfaces. Inspect motion-critical endpoints and intermediate states with suitable proxies; incidental hand contact does not establish another intended contact surface.

Before substantial reference-driven creation/polish is complete, obtain a separate critical sub-agent review following [shared evaluation](../blender-threejs-props/references/evaluation.md). Compare all major source components with actual multi-angle renders. Report local repair success alongside any remaining structural mismatch; topology metrics and clearance formulas supplement visual inspection.
